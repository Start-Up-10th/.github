## 🏠 왜 만들었나요?

매일 밤 기숙사 자치위원이 약 **200명**의 학생을 한 명씩 확인하며 입소 출석을 체크합니다.
Check UP은 출입구 기기의 카메라와 학생의 휴대폰으로 이 확인 작업을 줄입니다.

- 🙂 **얼굴 인식** — 출입구 기기 앞을 지나가면 여러 명을 한 번에 인식해 출석
- 📱 **QR** — 관리자 화면의 QR을 휴대폰으로 찍으면 출석
- 🔐 **DataGSM 로그인** — 학교 계정으로 로그인, 학생 정보는 DataGSM과 자동 동기화

<br/>

## ✨ 주요 기능

  <tr>
    <th>🧑‍🎓 학생</th>

    <td valign="top">

- DataGSM 로그인 · 서비스 이용 동의

- 호실 · 층별 출석 현황과 수동 수정
- 봉사 횟수 `+` / `−` 조정 · 당일 봉사자 지정
- 기숙사 공지 작성
